# Превью ссылок на новости доступны на сайте

28 октября 2026

Уже доступно на сервере.

- Ссылки на опубликованные новости отдают отдельные заголовок, описание и картинку для превью в мессенджерах.
- Для превью используется JPEG-версия обложки; изображения на странице новости сохраняют прежний формат.

Данные для превью проверены на рабочем сайте. Фактическая карточка в Telegram не проверялась отправкой сообщения; старые ссылки могут сохранять прежнее превью в кэше мессенджера.
