# Обновления за 2026-11-16

## Обновлённый внутриигровой магазин

Уже доступно на сервере.

**Категория:** Улучшения

- Магазин (/shop) получил новый вид: у каждого товара справа своя карточка с большой иконкой, описанием, выбором количества и ценой, а поиск теперь стоит в строке категорий
- Пополнение через кнопки «+»: готовые наборы монет и алмазов с ценой в рублях, а для своей суммы есть отдельная строка
- Появилась вкладка паков (строитель, ландшафт, фермер) со списком содержимого
- Окна промокода и наград колеса стали компактными, теперь они открываются по центру экрана

**Примечания:**
- Паки пока покупаются на сайте eldheim.online
