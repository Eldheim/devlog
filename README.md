# Eldheim devlog

Сырой журнал обновлений сервера Eldheim. На `main` живёт `devlog.md` — источник,
на ветке `updates` — дельта каждого пуша для сборщика патчноутов.

## Как выгружать обновления

1. Добавь в `devlog.md` секцию (новые выше):

   ```markdown
   ## ГГГГ-ММ-ДД — суть
   - факт один
   - факт два
   ```

2. Закоммить и запушь в `main`. Воркфлоу срабатывает только на пуши,
   меняющие `devlog.md` (`paths: ['devlog.md']`).

3. Через минуту в ветке `updates` появляется файл
   `updates/ГГГГ-ММ-ДД-<sha7>.md` — дельта этого пуша относительно предыдущего
   коммита, трогавшего `devlog.md`:

   | изменение         | что попадает в дельту         |
   |-------------------|-------------------------------|
   | новая секция      | целиком (заголовок + пункты)  |
   | изменённая секция | только добавленные строки     |
   | удалённая секция  | строка `удалено: <заголовок>` |

   Правка шапки/памятки (всё до первой секции `## `) дельту не создаёт.
   Самый первый коммит `devlog.md` — базлайн, для него дельты нет.
   Ветка `updates` создаётся скриптом автоматически при первой публикации.

## Куда смотрит сборщик патчноутов

Ветка `updates`, каталог `updates/` — по одному `.md` на каждый публикационный
пуш. Имя файла = дата публикации (UTC) + короткий sha коммита в `main`.
Внутри — заголовок `# Дельта девлога — <дата> (коммит <sha7>)` и секции с дельтой.

## Устройство

- `devlog.md` — журнал (формат описан в шапке файла).
- `scripts/publish_updates.py` — считает дельту и коммитит её в `updates`
  (только python3 stdlib).
- `.github/workflows/devlog-updates.yml` — push в `main` (devlog.md) → публикация.
