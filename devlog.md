# Eldheim — девлог сервера

Памятка по формату:
- одна секция = одно обновление; заголовок строго `## ГГГГ-ММ-ДД — суть`;
- под заголовком пункты `- ...`, по одному факту на строку;
- новые секции добавляются выше старых;
- правим только здесь, на main. При каждом пуше, трогающем этот файл,
  воркфлоу публикует дельту в ветку `updates`: новая секция — целиком,
  в изменённой — только добавленные строки, удалённая — строкой
  `удалено: <заголовок>`. Сборщик патчноутов читает ветку `updates`.
